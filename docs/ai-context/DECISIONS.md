# Decisions

## 2026-06-10: Static First

초기 버전은 서버 없는 정적 웹페이지로 만든다.

Reason:

- 요구사항의 핵심은 즉시 진입 가능한 밈형 인터랙션이다.
- 현재 프로젝트에 기존 프론트엔드/백엔드 구조가 없다.
- 실제 실시간 채팅은 별도 서버 선택이 필요하므로 초기 구현 범위에서 제외한다.

## 2026-06-10: Minimal Local Storage

개인 식별 정보는 저장하지 않고, 브라우저 로컬 상태만 사용한다.

Stored:

- 랜덤 닉네임
- 온보딩 닫힘 여부
- 음소거 설정
- 마지막 선택 의식
- 뮤트한 닉네임 목록
